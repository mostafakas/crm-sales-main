## Typography

| Element | Size | Weight | Color |
|---------|------|--------|-------|
| Page Title | 22px | Bold | #343434 |
| Section Title | 18px | Bold | #343434 |
| Card Title | 16px | Bold | #343434 |
| Label | 14px | Bold | #343434 |
| Body Text | 12px | Bold | #343434 |
| Secondary Text | 12px | Bold | #707070 |
| Placeholder | 12px | Bold | #707070 |
| Status Badge | 10px | Bold | Status Color |

---

## Spacing System

| Size | Usage |
|------|-------|
| 8px | Icon spacing, tight gaps |
| 12px | Card padding, element gaps |
| 16px | Panel padding, section gaps |
| 20px | Large gaps, section spacing |
| 24px | Major section spacing |
| 32px | Panel padding top/bottom |

---

## Border Radius

| Size | Usage |
|------|-------|
| 4px | Mini elements |
| 6px | Badge radius |
| 8px | Button, input, small cards |
| 10px | Dropdown, modals |
| 12px | Large cards, sections |

---

## Shadow & Effects

| Type | Usage |
|------|-------|
| shadow-sm | Card hover effects |
| shadow-lg shadow-[color]/20 | Active buttons |
| transition-all duration-300 | Smooth state changes |
| hover:bg-slate-200 | Inactive button hover |
| ring-2 ring-white/10 | Avatar rings |
